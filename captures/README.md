# 时缝实验记录

## 当前证据

[合成台架](bench-pulse/) 提供拟合锚点、留出事件和待校准采集表。拟合输入有 9 条锚点，独立留出 5 条事件。测试覆盖错配、重复设备时间、非单调映射、外推和微秒时间戳边界。台架报告预期的漂移约为 500 ppm，漂移校正后留出事件的最大绝对误差为 0 µs。

## 设备复测

1. 两台设备各自连续录音，用同一个固定位置的拍手或蜂鸣器每隔一段时间发出同步信号。尽量让两台设备与声源的距离接近。
2. 根据各自的采样位置与标称采样率换算整数微秒，按信号顺序配对，记录设备、采样率、间隔和配对方法。
3. 用跨越整个采集区间的部分事件拟合。提前选定中段和末段的留出事件，记录采用的残差阈值。
4. 运行 audit 和 score，记录保留与剔除的事件，比较中位与最大绝对误差。说明声音传播、峰值定位和采样精度可能带来的偏差。
5. 把可公开的事件表和报告放到新的采集子目录。保留原始记录或其校验和，确保结果可以复查。

## 开发与复核

项目由参赛者选定设备时钟校准方向，并明确要求可复现验证、公开仓库与独立的项目结构。AI 辅助实现、补充边界用例和整理复现说明。以下记录区分程序验证与设备实测。

| 检查 | 验证方式 |
| --- | --- |
| 校准能否识别明显错配 | 合成台架预先设定真值，用 audit 定位错配，用 score 比较仅校偏移和含漂移两种模型 |
| 负漂移与小幅抖动是否破坏结果 | 回归测试注入 −250 ppm、两处错配及微秒级抖动，要求两处错配被标记，并将三个留出点的误差控制在 35 µs 以内 |
| 真实设备上的效果 | 待按上面的设备复测步骤记录，完成后补充数据来源、配对依据和误差结果 |
